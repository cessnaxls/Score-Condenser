Score Condensor v22
- Visual OMR now has Music-only mode (default): excludes lyrics, prose, titles, captions, page numbers and footnotes.
- Historical / early-music recognition profile for scans and old print.
- OMR is explicitly source-faithful: preserves source staves/parts and does NOT condense during recognition.
- Explicit breve, long and maxima instructions.
- Page/system/staff/measure completeness instructions and sparse-result warnings.
- Selectable GPT-5.6 Luna (low-cost testing) or Terra (higher-accuracy) OMR model.
- API usage metadata returned by server for future cost instrumentation.
