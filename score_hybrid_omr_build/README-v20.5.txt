Score Condensor v20.5

Same-pitch duration precedence
- If a later, shorter note in another source voice has the same written pitch as a preceding longer note, the longer note takes precedence when the shorter note is fully covered by it or begins exactly at its end.
- The shorter duplicate note is omitted from engraving.
- Simultaneous same-pitch notes with different rhythms still use the existing tied rhythmic-splitting rule.
- The rule applies in both Literal and Intelligent transcription after transposition/octave processing and before chord/lane packing.

All v20.4 tie, C4 staff split, transposition, octave-transcription, rest-preservation, and raster-PDF behavior remains unchanged.
