Score Condensor v19

Changes from v18.1:
- Octave Transcription is now an optional checkbox under Intelligent Transcription. Intelligent mode no longer applies octave folding unless that checkbox is enabled. Literal mode never applies it.
- Same-pitch / same-onset notes with different durations are rhythmically re-spelled: longer notes are split at shorter-note duration boundaries and tied across the resulting segments. This preserves the sounding duration while exposing the independent shorter rhythm.
- Imported rests remain unchanged.
- Existing intelligent/literal mode selection, beaming pipeline, and raster-PNG PDF pipeline are retained.
